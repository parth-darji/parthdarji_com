Chore chart maker

By Parth Darji · Updated November 23, 2026

Add who's helping and the chores. Choose daily or weekly chores, and the maker rotates them so everyone gets a fair turn. Print it or save it as a PDF for the fridge.

Daily chores rotate each day so nobody is stuck with the same one; weekly chores are shared out across people. Tick the boxes when done.

Everything runs in your browser. Nothing you type is sent anywhere or stored on a server.

Questions

How do I make a fair chore chart?

List everyone and every chore, then rotate daily chores so each person does each job on different days, and share weekly chores out evenly.

Can I print the chore chart?

Yes. Tap Print or save as PDF; only the chart prints.
